ABOUT THIS UPDATE
=============================================================================

This Next Generation update of SUP F4SE was created through a collaboration
between the original mod author Tomm and Claude (Anthropic's AI assistant)
using Claude Code CLI.

The primary challenge was updating all hardcoded memory addresses to work
with the new Fallout 4 executable, which required:

  - Implementing Address Library integration for version-independent addressing
  - Reverse-engineering and mapping 35+ function addresses to their new
    Address Library IDs for the NG database
  - Creating a robust address resolution system that loads offsets at runtime
  - Extensive testing and iteration to resolve crashes and compatibility issues

PROJECT STATISTICS:
  - Estimated tokens used: ~500,000+ across multiple sessions
  - Development time: ~8-10 hours of active Claude Code sessions
  - Lines of code analyzed/modified: 27,786 lines across 55 source files
  - Address Library IDs mapped: 35 game functions

=============================================================================
INSTALLATION
=============================================================================

Using Vortex/Mod Manager:
  1. Install F4SE 0.7.7 manually (copy files to Fallout 4 folder)
  2. Install "Address Library for F4SE Plugins" from Nexus
  3. Install this mod using your mod manager
  4. Launch game using f4se_loader.exe

Manual Installation:
  1. Extract SUP_F4SE.dll to:
     <Fallout 4>\Data\F4SE\Plugins\SUP_F4SE.dll
  2. Ensure you have the Address Library database file:
     <Fallout 4>\Data\F4SE\Plugins\version-1-11-191-0.bin
